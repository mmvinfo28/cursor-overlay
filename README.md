# Cursor Overlay

Windows 11 Electron overlay: follows the cursor, reads the focused text field via UI Automation, and fires a capture (selected text or screenshot crop) on double-tap Shift. Capture end of the Crewboard hackathon project.

```bash
npm install
start.cmd          # overlay
start-reader.cmd   # overlay + live field reader
stop.cmd           # kill everything
```
